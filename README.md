# OQVIAN VULNORBIT

A local-first vulnerability intelligence and risk prioritization demo.

> **Demo status:** project setup is in progress. This repository does not provide production server monitoring, vulnerability prevention, or automated patching.

## Scope

The demo will correlate a fictional asset inventory with public OSV vulnerability records and CISA Known Exploited Vulnerabilities (KEV) data. It will show evidence-backed findings, explain prioritization, and provide a simulated investigation and remediation workflow.

All customer organizations and assets are fictional. Intelligence data will be labeled with its source and retrieval freshness. The application is intended to run locally.

## Development status

The first end-to-end detection workflow is under development. Setup, demo, and test instructions will be added as the local application is built.
